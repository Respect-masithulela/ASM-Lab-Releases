# ASM Lab downloads

ASM Lab is mine ventilation and heat software: airflow, fans, walls, heat and humidity, bulk air coolers, heat-stress indices and re-entry times.

## Get it
- **Windows:** [latest installer](https://github.com/Respect-masithulela/ASM-Lab-Releases/releases/latest) (`ASM-Lab-Setup-….exe`). Installed copies offer updates themselves.
- **Mac (and any other computer):** open the web version: https://respect-masithulela.github.io/ASM-Lab-Releases/ . It needs a licence key, like the Windows app.
- **In the app:** the **Downloads** button at the top right opens the latest release page.

## Guides
- [Quick start](guides/QUICK-START.md): your first model, step by step.
- [Conversion kit](conversion-kit/README.md): file formats, converters and a worked example, for people and their AI models who bring models in from other tools or build projects in code.

Only the installer, the Mac link and the guides are published here. Release notes are on each release page.
